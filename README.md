# Живой маркетинг

Статический лендинг курса-практикума «Живой маркетинг: JTBD, CJM и AI».

## Публикация

Проект рассчитан на публикацию через Vercel как статический сайт:

- Framework Preset: Other
- Build Command: пусто
- Output Directory: пусто

Файлы сайта лежат в корне репозитория:

- `index.html`
- `landing.html`
- `privacy.html`
- `privacy-policy.html` — совместимый переход на `/privacy`
- `assets/`

## Обязательное правило аналитики

На каждой HTML-странице сайта должен быть установлен счетчик Яндекс.Метрики `109290984`.

Перед публикацией новой страницы проверь:

- в `<head>` есть блок `Yandex.Metrika counter`;
- внутри блока есть `ym(109290984, 'init', ...)`;
- сразу после открытия `<body>` есть `<noscript>`-картинка `https://mc.yandex.ru/watch/109290984`;
- это правило относится ко всем новым страницам: лендинг, политика, согласие, служебные переходы и будущие страницы.

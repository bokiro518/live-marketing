# Живой маркетинг

Статический лендинг курса-практикума «Живой маркетинг: JTBD, CJM и AI».

## Публикация

Проект рассчитан на публикацию через Vercel как статический сайт:

- Framework Preset: Other
- Build Command: пусто
- Output Directory: пусто

Файлы сайта лежат в корне репозитория:

- `index.html`
- `landing.html`
- `privacy.html`
- `privacy-policy.html` — совместимый переход на `/privacy`
- `assets/`

## Обязательное правило аналитики

На каждой HTML-странице сайта должны быть установлены счетчик Яндекс.Метрики `109290984` и пиксель VK Ads / Top.Mail.Ru `3767299`.

Перед публикацией новой страницы проверь:

- в `<head>` сразу после `charset` и `viewport` есть блок `Yandex.Metrika counter`;
- внутри блока есть `ym(109290984, 'init', ...)`;
- сразу после Метрики есть блок `Top.Mail.Ru counter`;
- внутри блока есть `_tmr.push({id: "3767299", type: "pageView", ..., pid: visitorId})`;
- сразу после открытия `<body>` есть `<noscript>`-картинка `https://mc.yandex.ru/watch/109290984`;
- сразу после нее есть `<noscript>`-картинка `https://top-fwz1.mail.ru/counter?id=3767299;js=na`;
- `pid` берется из анонимного постоянного идентификатора посетителя в браузере; не подставлять туда телефон, имя, email или другие данные заявки.
- это правило относится ко всем новым страницам: лендинг, политика, согласие, служебные переходы и будущие страницы.
